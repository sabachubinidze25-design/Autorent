# AutoRent – ავტომობილების გაქირავება, Car rental portal built with Django

საკურსო პროექტი: მანქანების გაქირავების პორტალი. დაწერილია **Python / Django-ზე**, ინტერფეისი **HTML და CSS**-ია. საიტს აქვს საკუთარი ბაზა (SQLite), მოდელები, მომხმარებლების სისტემა და JSON API.

## გაშვება

```bash
python -m venv venv
venv\Scripts\activate            
pip install -r requirements.txt
python manage.py migrate         
python manage.py runserver
```

გახსენით http://127.0.0.1:8000/ , დარეგისტრირდით და მანქანები დაამატეთ გვერდზე `/cars/add/`.

ადმინ-პანელი: `python manage.py createsuperuser`, შემდეგ http://127.0.0.1:8000/admin/

### წესები
- **ქირაობა:** არჩევთ დაწყების და დასრულების თარიღს. ორივე დღე ითვლება (`დღეები = დასრულება − დაწყება + 1`).
  წარსული თარიღი არ შეიძლება, მაქსიმუმ 365 დღე. საკუთარი მანქანის დაქირავება შეუძლებელია.
  თუ ამ თარიღებში მანქანა უკვე დაკავებულია, ქირაობა არ მოხდება (ზედიზედ თარიღები შეიძლება).
- **გაუქმება:** შესაძლებელია მხოლოდ დაწყების თარიღამდე. გაუქმების შემდეგ თარიღები თავისუფლდება და მფლობელს შეტყობინება მიუვა.
- **გული:** პირველი დაჭერა ამატებს მოწონებაში, მეორე დაჭერა ხსნის.
- **პოპულარული მანქანები:** ქულა = აქტიური ქირაობები + მოწონებები, ყველაზე მაღალი ქულის 4 მანქანა.

## JSON API

ძირითადი მისამართი `/api/` (`GET /api/` აჩვენებს ყველა endpoint-ს). შესვლის შემდეგ მიღებული ტოკენი
უნდა გაიგზავნოს ჰედერში: `Authorization: Token <ტოკენი>`. მონაცემები შეიძლება იყოს JSON-ად
(`Content-Type: application/json`); მანქანის დამატებას სჭირდება `multipart/form-data`.

| მეთოდი და მისამართი | ავტორიზაცია | დანიშნულება |
|---|---|---|
| `POST /api/register/` | არა | `first_name, last_name, phone, email, password` |
| `POST /api/login/` | არა | `phone, password` → `{"token", "user"}` |
| `GET /api/me/` | კი | მიმდინარე მომხმარებელი |
| `GET /api/cars/` | არა | სია; პარამეტრები: `brand, city, q, capacity, start_year, end_year, min_price, max_price, sort, page, page_size` |
| `POST /api/cars/` | კი | მანქანის დამატება (`brand, model, year, price, capacity, fuel_capacity, transmission, city, image1-3`) |
| `GET /api/cars/<id>/` | არა | ერთი მანქანა |
| `POST /api/cars/<id>/like/` | კი | მოწონება / მოწონების მოხსნა |
| `POST /api/cars/<id>/rent/` | კი | `{"start_date": "2026-12-01", "end_date": "2026-12-03"}` (409, თუ თარიღები დაკავებულია) |
| `GET /api/rentals/` | კი | ჩემი ქირაობები |
| `POST /api/rentals/<id>/cancel/` | კი | ქირაობის გაუქმება (409, თუ უკვე დაიწყო) |
| `GET /api/favorites/` | კი | მოწონებული მანქანები |
| `GET /api/notifications/` | კი | შეტყობინებები |

სიის პასუხი: `{"count", "page", "page_size", "total_pages", "has_next", "has_previous", "results": [...]}`.
შეცდომა: `{"error": "..."}` ან `{"error": "...", "fields": {...}}`.


## დახმარების ელფოსტა

გვერდი `/support/` აგზავნის შეტყობინებას მისამართზე `SUPPORT_EMAIL` (`Autorentsupport@gmail.com`).
SMTP პარამეტრების გარეშე წერილი უბრალოდ იბეჭდება ტერმინალში. ნამდვილი გაგზავნისთვის (Windows cmd; macOS/Linux-ზე `export`):

```
set EMAIL_HOST_USER=Autorentsupport@gmail.com
set EMAIL_HOST_PASSWORD=თქვენი-16-ასოიანი-App-password
```

სპამისგან დაცვა: ფარული ველი და 60 წამიანი პაუზა გაგზავნებს შორის.
